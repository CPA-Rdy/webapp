# CPA Ready

A personal CPA board exam study tracker designed to help
reviewees organize their preparation.

## Features

- 📚 Subject and topic tracking
- 📊 Progress dashboard
- 📝 Study history
- 🎯 Custom subjects and topics
- 🎥 Video lecture tracking
- 🏆 Achievements
- 📅 Study calendar
- 📱 Installable as a PWA

## How to Use

1. Open the application.
2. Set up your subjects and topics.
3. Track your progress as you study.
4. Review your dashboard to monitor your preparation.

## Technology

- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
